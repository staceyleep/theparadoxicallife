# The Paradoxical Life

Website for Charis Patrick's psychotherapy practice (theparadoxicallife.com).

Plain HTML and CSS, no build step. Pages: `index.html`, `about.html`, `services.html`, `faq.html`, `contact.html`. Styles are in `style.css`.

To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
